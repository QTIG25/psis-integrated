# PSIS - Integrated

## What is PSIS Integrated?

### PSIS Integrated is a highly secure intelligence terminal combining OSINT sources for PSIS Intelligence Agents.

## Who is PSIS

### PSIS or the People's Secret Intelligence Service is a group dedicated to stopping online fraud, scam calls and more.
### We use OSINT or Open Source Intelligence tools which help us find information about people, scams and more. Open Source Intelligence is publicly available information however special OSINT tools scans across the internet and compares similarities and displays know information.
