System Architecture & Security SpecificationZero-Trust Whitepaper

1.0 Decryption-as-Authentication Model

This application contains no hardcoded plain-text password comparison strings (`if/else` checks). Entering a passphrase derives an AES-256-GCM key via PBKDF2 (100,000 iterations). Bypassing the login gate in the browser console results in an empty, non-functional application state because operational keys are never loaded into memory without cryptographic verification.

2.0 Encrypted Offline Vault Persistence

Data loss risks associated with volatile RAM or cleared browser caches are mitigated via encrypted JSON file exports (`.psis`). Case files are encrypted client-side using `window.crypto.subtle` before being downloaded to local physical media.
